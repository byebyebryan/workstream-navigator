# Workstream Navigator documentation

## Start here

- The top-level [README](../README.md) is the product landing page and
  source-install quick start.
- [Product captures](media/README.md) show the actual navigator renderer with
  deterministic, privacy-safe fixture data.
- `wsnav --help` and `wsnav host doctor <alias>` are the authoritative runtime
  command and compatibility checks for an installed build.

## Current contract

- [V1 design](design.md) is the product and architecture authority.
- [V1 roadmap](roadmap.md) owns delivery order, checkpoint status, and exit
  gates. D0 through D7.6 are complete; the source remains an operator beta,
  not a tagged distribution.

## Historical evidence

[Evidence](evidence/README.md) contains dated, sanitized acceptance records,
design spikes, and provider studies. Those files preserve the candidate,
environment, procedure, and limitations they tested. Their historical
protocol/schema values, test counts, shortcuts, and presentation descriptions
do not replace the current design, roadmap, or operator guide.

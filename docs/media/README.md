# Historical product captures

These frozen captures show the pre-D16 baseline two-pane presentation at the
normal 141×60 terminal layout: a fixed 32-column navigator, one tmux divider
column, and a wide 108-column provider pane. They depict the initial
Navigator/provider layout only and do not show D16's
Workstreams/Projects/Archived navigator.
D12's optional temporary utility shell below the provider is not shown. The
adjacent Codex pane is a clearly labelled fixed demonstration surface, never a
capture of a real provider session. No provider terminal, prompt, response,
filesystem path, host identity, credential, or durable Workstream identifier
is captured or committed.

| Capture | What it shows |
| --- | --- |
| [Animated tour](workstream-tour.gif) | Open an existing Workstream, fork from its settled native turn, then park and resume without replacing the native workflow. |
| [Open](screenshots/open-workstream.png) | The initial two-pane Workstreams view: project-first context, activity age, lifecycle markers, and compact keyboard hints. |
| [Fork](screenshots/fork-workstream.png) | An independent destination Workstream beside its still-working source. |
| [Park and resume](screenshots/park-and-resume.png) | A resumed native thread keeps its result attention while another Workstream remains parked. |

The SVG sources, PNG previews, and GIF tour remain committed only as historical
design evidence. Their pre-D16 generator was deliberately removed with the
retired navigator. Do not refresh or present these assets as current UI;
replacement captures belong to a later, explicitly scoped UI/documentation
checkpoint after the current interaction design is settled.
